## 🌟 Featured Modules

### 🧠 [GenAI Series P0: RAG Foundations & AI Agents](file:///d:/agentic-ai-lab/GenAI/series/p0/Readme.md)
* **Document Loaders (`RAG_Doc_Loader.ipynb`)**: Local text, web scraping (`WebBaseLoader`), and Wikipedia ingestion.
* **Document Chunking (`RAG_Doc_Splitter.ipynb`)**: Context preservation using `RecursiveCharacterTextSplitter`.
* **Vector DB & Retrieval (`RAG_Vector.ipynb`)**: 3,072-dim embeddings via `GoogleGenerativeAIEmbeddings` (`gemini-embedding-2-preview`) and persistent `Chroma` Vector Database.
* **Web Research Agent (`app/` & `search_agent.ipynb`)**: Streamlit & LangGraph conversational web research assistant.
