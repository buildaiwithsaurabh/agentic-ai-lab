# Day 15 - Request Body & Pydantic Models

## Overview

Day 15 focused on understanding how APIs receive data from clients using POST requests and Request Bodies.

I also learned how FastAPI uses Pydantic Models for data validation and type checking.

---

## Topics Covered

### Request Body

Used to send data from client to server.

### POST Requests

Used to create new resources.

### Pydantic Models

Used for:

- Data Validation
- Type Checking
- Request Parsing

---

## Projects Built

### 1. Request Body Example

### 2. Pydantic Model Example

Learned how to define structured data models.

### 3. Product Create API

Built a Product API that:

- Returns Product Data
